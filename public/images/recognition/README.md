# Recognition & Community Impact images

Drop web-optimized images (WebP preferred, ~400x225 for card thumbnails) here, e.g.:

- `newage-press.webp` — press screenshot (Cloud Native Days Bangladesh 2026, New Age)
- `cncf-swag.webp` — CNCF hoodie/swag photo
- `kcd-chattogram.webp` — KCD Chattogram event photo

Then wire them up in `src/components/RecognitionSection.jsx` by adding
`image: '/images/recognition/<file>.webp'` and a descriptive `imageAlt`
to the matching entry (see the commented placeholders there).
